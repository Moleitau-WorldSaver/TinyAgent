# Issue-001

## 背景与用户目标

建立 TinyAgent 最小 Agent Loop，支持用户输入、模型响应、工具调用、工具结果回传和最终文本输出。

## 当前现状

仓库最初没有可运行 Agent。当前基础实现已经支持模型响应结构、工具注册表、参数校验、echo 工具和 50 轮限制。

## 预期交付物

- Python Agent Loop。
- 模型适配层。
- 工具注册表。
- 结构化工具调用。
- 工具结果回传。
- 50 轮限制。
- CLI、配置示例和自动化测试。

## 验收标准

- 纯文本响应可以直接输出。
- 工具调用可以执行并继续下一轮。
- 未知工具和参数错误不会导致崩溃。
- 达到 50 轮后停止。
- 测试不依赖真实 API Key。

### 明确不做

- 流式输出。
- 多 Agent。
- RAG。
- 数据库。
- Web UI。
- 权限闸门。
- Session 恢复。
