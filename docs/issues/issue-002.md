# Issue-002

## 背景与用户目标

为工具提供独立名称、描述和参数 Schema，并支持多个工具调用的并行执行。

## 当前现状

已有通用工具注册表和 echo 工具，但没有完整工具目录、Provider 边界和并行工具调用。

## 预期交付物

- 九个工具定义。
- Search 和 Weather Provider。
- Mock Provider。
- calculator 确定性执行。
- 多工具并行执行。
- 原始调用顺序回传。

## 验收标准

- 每个工具都有独立 Schema。
- 未注册工具被拒绝。
- 多工具可以并行执行。
- 一个工具失败不会丢失其他结果。
- 结果按模型原始顺序回传。

### 明确不做

- 真实 Bash。
- 真实搜索和天气服务。
- DeepSeek 真实接入。
- 任务依赖。
- 权限闸门。
