# Issue-004

## 背景与用户目标

建立项目级 Task 目录和跨会话 Todo 持久化，让用户可以直接编辑任务 Markdown。

## 当前现状

已有 Task 基础实现，但需要统一 Task.md、具体任务文件、任务 ID、状态和 Write 边界。

## 预期交付物

- `Task/Task.md`。
- 编号任务文件。
- 稳定任务 ID 和状态。
- Todo 创建、读取、更新、完成和取消。
- Task 目录限定写入。
- 跨会话读取。

## 验收标准

- 任务可以跨进程读取。
- 用户手动修改可以保留。
- 重复 ID 被拒绝。
- Task 目录外写入被拒绝。
- 第一版不执行任务依赖。

### 明确不做

- 任务调度。
- 多 Agent 派发。
- 数据库。
- 真实 Bash。
- 上下文压缩。
