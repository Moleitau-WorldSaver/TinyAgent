# Issue-005

## 背景与用户目标

建立 Hook 管理系统，并在 Bash 执行前提供黑名单、风险策略和用户确认三道权限闸门。

## 当前现状

已有 Agent Loop、工具注册、DeepSeek、Task 和基础 Hook 实现，但需要统一 Hook 生命周期和权限策略文档。

## 预期交付物

- HookManager。
- Hook Context 和 Decision。
- 六个生命周期入口。
- Bash 黑名单。
- 风险正则。
- 工作区路径检查。
- 批量高风险确认。
- 上下文压缩 Hook 接口。

## 验收标准

- 黑名单命令直接阻断。
- 风险命令进入用户确认。
- 用户拒绝会生成工具错误。
- Hook 异常时安全 Hook 默认阻止。
- 工具调用 ID 和错误结果保持正确。

### 明确不做

- 真实上下文压缩算法。
- 永久授权。
- 复杂 Shell 解析。
- 真实破坏性 Bash。
- 多 Agent 权限管理。
