# Issue-009

## 背景与用户目标

确定性压缩后上下文仍可能超出预算。系统需要调用摘要工具提炼旧内容，并在摘要失败后按照确定性规则降级，避免无限重试或发送超限请求。

## 当前现状

- Issue-008 提供前三道确定性压缩管线。
- Session 保存完整原始结果。
- 尚无摘要工具、长度限制和失败降级流程。
- 当前 DeepSeek 是唯一模型 Provider。

## 预期交付物

- 摘要工具读取 Session 原始内容。
- 摘要最大长度 1000 tokens。
- 摘要失败最多重试一次。
- 摘要结果写入新的 Session 记录。
- 上下文标记已经发生压缩。
- 摘要失败后使用确定性规则。
- 仍超限时停止本轮模型调用并提示用户。

## 验收标准

- 摘要不会修改原始 Session。
- 摘要输出不超过限制。
- 摘要最多重试一次。
- 摘要失败后进入确定性降级。
- 降级后仍超限时不调用模型。
- 用户能看到上下文压缩提示。
- `python -m unittest discover -s tests -v` 通过。

### 明确不做

- 其他模型 Provider。
- 永久摘要缓存。
- 完整会话恢复。
- 真实 Bash 执行。
- 多模型摘要。
